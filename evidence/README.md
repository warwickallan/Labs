# Evidence repository

Every important claim in the model and report traces here. One predictable
tree; screenshots and capture notes named `NNN-short-description.png` /
`NNN-short-description.md`, numbered in capture order within each folder.

Each file gets an `E-NNN` id in the model's top-level `evidence[]` index
(`scripts/validate_model.py` verifies every reference resolves and every
indexed path exists).

```
helpdesk-admin/          parent structure, Helpdesk Type list, shared-vs-type-specific
reactive-helpdesk/
  statuses/
  operative-statuses/
  actions/
  action-configurator/   every tab/section/control of Add/Edit Action
  mobile/
  roles/
  timers/
  screenshots/           general captures not specific to one folder above
planned-helpdesk/        structural-parity evidence only (unless instructed)
```
